# .NET binding

The .NET package P/Invokes the stable C ABI and runs every native call on one dedicated managed thread to preserve thread affinity across async continuations.

See [.NET compatibility and installation](DOTNET.md) for the upcoming
Framework 4.8 / .NET Standard 2.0 targets, native deployment and verified package
consumer results. Version 0.33.1 includes the compatible target frameworks.
