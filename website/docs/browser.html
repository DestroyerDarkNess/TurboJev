Browser / WASM

Run locally in a web worker with optional WebGPU.

npm ↗
npm install @turbojev/web
app.ts
import { TurboJevWeb } from "@turbojev/web";

const jev = await TurboJevWeb.load({
  model: "https://example.com/model.onnx",
  wasmModuleUrl: "/turbojev_wasm.js",
  runtimeModuleUrl: "/my-runtime.js",
  runtimeOptions: {device: "wasm", dtype: "q4"},
});
const result = await jev.classify("My package never arrived",
  ["billing", "shipping", "support"]);
console.log(result.choice);
await jev.close();

Included vanilla studio: python samples/build.py web.

Try the browser playground

The playground runs real inference in a worker. Select the input type before loading a model. Unload the current model to change it. Downloads start only when you press Load.

Model selection

InputModelsMethod
TextSmolLM2 135M / 360M, Qwen2.5 0.5B, Qwen3 0.6BCandidate-token logits
ImageCLIP B/32, CLIP B/16Image–text similarity
ImageSmolVLM 256M, SmolVLM2 256MVision-language candidate scoring
AudioCLAP HTSATSound–text similarity
VideoCLIP or SmolVLM2Average logits from four sampled frames

Media limits

Files must be at most 24 MB. Audio is mixed to mono at 48 kHz and must be 10 seconds or shorter. Video must be 60 seconds or shorter; this demo scores four frames independently, without motion analysis or the audio track. Small models can return incorrect decisions.

Runtime assets

The package supplies the worker bridge. Host a compiled TurboJev WASM module and an adapter that implements the runtime contract at the URLs above. The repository includes a Transformers.js adapter; the samples/build.py web command prepares a complete runnable example.

Troubleshooting

If WebGPU is unavailable, select CPU. If initialization runs out of memory, unload the model and try SmolLM2 135M or CLIP B/32. Cancel terminates the worker. Download progress is per file; model initialization can continue after a file reaches 100%.
