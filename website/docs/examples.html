Examples

Repository samples/ build this checkout. The separate TurboJev.Demos repository uses published packages and CDN assets. Each Python demo owns its implementation and local assets; it does not invoke another demo.

Run typed-field samples

PowerShell · repository root 
py samples/build.py native --arch x64
py samples/run.py python --model C:/models/model.gguf --generate
py samples/run.py ts --model C:/models/model.gguf --generate
py samples/run.py csharp --model C:/models/model.gguf --generate
py samples/run.py rust --model C:/models/model.gguf --generate
