Node / TypeScript

Worker-backed native calls with typed results and clean async shutdown.

npm ↗
npm install @turbojev/node
decision.ts
import { TurboJev } from "@turbojev/node";

const jev = await TurboJev.load({model: "./model.gguf", nGpuLayers: 0, nThreads: 4});
try {
  const result = await jev.classify("My package arrived broken.", [
    "billing", "shipping", "technical", "other",
  ]);
  console.log(result.choice, result.probabilities);
} finally {
  await jev.close();
}

Text and media source: TS sample ↗

Evaluate an image

Use a multimodal runtime rather than a text-only GGUF model. The sample runner configures the SmolVLM2 worker for you.

Terminal
python samples/multimodal/setup.py vision
python samples/run.py ts --media photo.jpg --modality image --question "What animal is shown?" --options "A cat" "A dog"

Once the engine is configured with that runtime, pass the same media envelope to evaluate:

media.ts
import { readFile } from "node:fs/promises";

const result = await engine.evaluate({
  state: {
    contract: "turbojev.media.v1",
    modality: "image",
    base64: (await readFile("photo.jpg")).toString("base64"),
  },
  questions: {
    scene: {
      type: "choice",
      instructions: "What animal is shown?",
      criteria: { cat: "A cat", dog: "A dog" },
    },
  },
});
console.log(result.answers.scene);
