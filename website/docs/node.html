Node / TypeScript

Worker-backed native calls with typed results and clean async shutdown.

npm ↗
npm install @turbojev/node
decision.ts 
import { TurboJev } from "@turbojev/node";



const jev = await TurboJev.load({ model: "./model.gguf", nGpuLayers: 0, nThreads: 4 });

try {

  const result = await jev.evaluate({

    state: { message: "My package arrived broken." },

    questions: {

      department: {

        type: "choice",

        instructions: "Which department should handle this?",

        criteria: {

          billing: "Payments",

          shipping: "Delivery",

          technical: "Product issue",

          other: "Other",

        },

      },

    },

  });

  console.log(result.answers.department);

} finally {

  await jev.close();

}

Evaluate an image

Load a supported vision GGUF and its matching projector. Both are inputs to the same native host; no external Python worker is required on this path.

load-media.ts 
const engine = await TurboJev.load({
  model: "./vision-model.gguf",
  mmproj: "./matching-mmproj.gguf",
  device: "cpu",
  nCtx: 8192,
  nSeqMax: 1,
});

Once the engine is configured with that runtime, pass the same media envelope to evaluate:

media.ts 
import { readFile } from "node:fs/promises";

const result = await engine.evaluate({
  state: {
    contract: "turbojev.media.v1",
    modality: "image",
    base64: (await readFile("photo.jpg")).toString("base64"),
  },
  questions: {
    scene: {
      type: "choice",
      instructions: "What animal is shown?",
      criteria: { cat: "A cat", dog: "A dog" },
    },
  },
});
console.log(result.answers.scene);

Generate typed fields

Call inside the same engine lifecycle shown above. A skipped field is absent; it is not a null value.

fields.ts 
const response = await jev.generate({
  context: "Invoice total: 324.50 GBP. Payment is overdue.",
  questions: {
    total: { type: "number", instructions: "What is the total in GBP?" },
    overdue: { type: "boolean", instructions: "Is payment overdue?" },
    reminder: {
      type: "string",
      when: { overdue: true },
      depends_on: ["total"],
      instructions: "Write one short payment reminder.",
    },
  },
  thinking: false,
  text_max_tokens: 128,
  numeric_max_tokens: 64,
});
console.log(response.result, response.skipped, response.usage);

For unordered routing, configure execution: {orderRobustness: "balanced"} at load time. For finite generated fields, use their own permutations setting. See all field options and ordering costs.
