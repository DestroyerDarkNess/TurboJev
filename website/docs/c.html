C ABI

Stable UTF-8 JSON ABI for C, Zig, Go, and other FFI hosts.

header ↗
smoke.c 
#include "turbojev.h"
#include <stdio.h>

int main(void) {
    tj_engine *engine = NULL;
    if (tj_engine_open_json("{\"model\":\"./model.gguf\"}", &engine) != TJ_OK) return 1;
    char *json = NULL;
    const char *request = "{\"state\":{\"message\":\"My package arrived broken.\"},\"questions\":{\"route\":{\"type\":\"choice\",\"instructions\":\"Which team?\",\"criteria\":{\"billing\":\"Payments\",\"shipping\":\"Delivery\"}}}}";
    int rc = tj_engine_evaluate_json(engine, request, &json);
    if (rc == TJ_OK) { puts(json); tj_string_free(json); }
    tj_engine_close(engine);
    return rc != TJ_OK;
}

The ABI uses opaque handles, explicit string ownership, and thread-local errors.

Generate typed fields

Use the same handle and ownership rules as evaluation.

fields.c 
const char *fields =
    "{\"context\":\"Invoice total: 324.50 GBP.\","
    "\"questions\":{\"total\":{\"type\":\"number\","
    "\"instructions\":\"What is the total in GBP?\"}},\"thinking\":false}";
char *output = NULL;
int status = tj_engine_generate_json(engine, fields, &output);
if (status == TJ_OK) { puts(output); tj_string_free(output); }

The shim ABI is version 10. Build C dependencies against matching libraries. Load JSON accepts execution.orderRobustness; generated fields accept the options described under typed fields.
