.NET / C#

NuGet package with native assets for three Windows architectures.

NuGet ↗
dotnet add package TurboJev --version 0.28.3
Program.cs
using TurboJev;

await using var jev = await TurboJevEngine.LoadAsync(new {
    model = "./model.gguf", nGpuLayers = 0, nThreads = 4
});
var json = await jev.ClassifyJsonAsync(
    "My package arrived broken",
    ["billing", "shipping", "technical", "other"]);
Console.WriteLine(json);

The package carries win-x86, win-x64, and win-arm64 native assets.

Evaluate an image

Prepare the SmolVLM2 worker and run the complete .NET sample. The runner supplies the worker environment and native library paths.

Terminal
python samples/multimodal/setup.py vision
python samples/run.py csharp --media photo.jpg --modality image --question "What animal is shown?" --options "A cat" "A dog"

With a multimodal engine, serialize the portable request and call EvaluateJsonAsync:

Media.cs
using System.Text.Json;

var request = new {
    state = new {
        contract = "turbojev.media.v1",
        modality = "image",
        base64 = Convert.ToBase64String(
            await File.ReadAllBytesAsync("photo.jpg")),
    },
    questions = new {
        scene = new {
            type = "choice",
            instructions = "What animal is shown?",
            criteria = new { cat = "A cat", dog = "A dog" },
        },
    },
};
Console.WriteLine(await engine.EvaluateJsonAsync(
    JsonSerializer.Serialize(request)));
