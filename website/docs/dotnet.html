.NET / C#

NuGet package with native assets for three Windows architectures.

NuGet ↗
dotnet add package TurboJev
Program.cs 
using TurboJev;

using System.Text.Json;



await using var jev = await TurboJevEngine.LoadAsync(new {

    model = "./model.gguf", nGpuLayers = 0, nThreads = 4

});

var request = new { state = new { message = "My package arrived broken" }, questions = new { department = new { type = "choice", instructions = "Which department?", criteria = new { billing = "Payments", shipping = "Delivery", technical = "Product issue", other = "Other" } } } };

var json = await jev.EvaluateJsonAsync(JsonSerializer.Serialize(request));

Console.WriteLine(json);

The package carries win-x86, win-x64, and win-arm64 native assets.

Evaluate an image

Load a supported vision GGUF and its matching projector before sending image evidence.

await using var engine = await TurboJevEngine.LoadAsync(new {

    model = "./vision-model.gguf", mmproj = "./matching-mmproj.gguf",

    device = "cpu", nCtx = 8192, nSeqMax = 1

});

With a multimodal engine, serialize the portable request and call EvaluateJsonAsync:

Media.cs 
using System.Text.Json;

var request = new {
    state = new {
        contract = "turbojev.media.v1",
        modality = "image",
        base64 = Convert.ToBase64String(
            await File.ReadAllBytesAsync("photo.jpg")),
    },
    questions = new {
        scene = new {
            type = "choice",
            instructions = "What animal is shown?",
            criteria = new { cat = "A cat", dog = "A dog" },
        },
    },
};
Console.WriteLine(await engine.EvaluateJsonAsync(
    JsonSerializer.Serialize(request)));

Generate typed fields

Use the loaded engine and serialize the same portable request.

Fields.cs 
var fields = new {
    context = "Invoice total: 324.50 GBP. Payment is overdue.",
    questions = new {
        total = new { type = "number", instructions = "What is the total in GBP?" },
        overdue = new { type = "boolean", instructions = "Is payment overdue?" },
        reminder = new { type = "string", when = new { overdue = true },
                         depends_on = new[] { "total" },
                         instructions = "Write one short payment reminder." }
    },
    thinking = false, text_max_tokens = 128, numeric_max_tokens = 64
};
Console.WriteLine(await jev.GenerateJsonAsync(JsonSerializer.Serialize(fields)));

Load-time choice correction uses execution = new { orderRobustness = "balanced" }. Generated field enums use permutations independently. See field options.
