Multimodal

Native llama.cpp and browser llama.cpp/WASM support the portable media envelope when the loaded model, matching projector and runtime build implement that modality. A text GGUF alone does not supply vision or audio.

Load a paired GGUF model and projector

media.py
import base64
from pathlib import Path
from turbojev import TurboJev

with TurboJev.load("./vision-model.gguf", mmproj="./matching-mmproj.gguf",
                   device="cpu", n_ctx=8192, n_seq_max=1) as jev:
    response = jev.evaluate({
        "state": {"contract": "turbojev.media.v1", "modality": "image",
                  "base64": base64.b64encode(Path("photo.jpg").read_bytes()).decode("ascii")},
        "questions": {"scene": {"type": "choice", "instructions": "What animal is shown?",
                                "criteria": {"cat": "A cat", "dog": "A dog"}}},
    })
    print(response["answers"]["scene"])

Evidence formats

InputEnvelopeRuntime requirement
Imagemodality: "image", base64Vision encoder and matching projector
Audiomodality: "audio", base64Supported audio model/projector and audio decoding
Video framesmodality: "video", frames: [{timestamp_ms, base64}]Vision runtime; host decodes frames in timestamp order

Optional text provides context alongside media. Video containers must be decoded by the host; TurboJev does not invoke ffmpeg/ffprobe executables. Ordered frames do not prove motion understanding and do not include the audio track.

Typed extraction

For generate, place the same envelope in context and define scalar fields, such as a receipt total and currency. The response uses result, not answers. Field workflows preserve media bytes while adding dependency answers. Set thinking: false; native media reasoning and browser reasoning return an explicit unsupported error.

Model quality and browser limits

The playground offers CLIP/CLAP similarity and LFM2 vision/audio GGUF paths. Similarity models do not follow arbitrary instructions. Browser audio GGUF remains experimental: the recorded Node/WASM adapter probe is not equivalent to qualification in every browser. Downloads, memory and preprocessing can dominate latency. See browser models and limits.
