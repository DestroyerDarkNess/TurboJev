Quickstart

Install the published package for your language. Native Node, Python and .NET packages currently include Windows x86, x64 and ARM64 libraries. Rust can build from source; browser WASM is independent of the host CPU architecture. Download a GGUF supported by the selected llama.cpp build, then pass its local path.

Terminal 
python -m pip install --upgrade turbojev

npm install @turbojev/node

dotnet add package TurboJev

cargo add turbojev

cargo add turbojev-runtime-llamacpp --features ffi
quickstart.py 
from turbojev import TurboJev

with TurboJev.load("./model.gguf", device="cpu", n_ctx=8192, n_seq_max=1) as jev:
    response = jev.evaluate(
        {
            "state": "My package arrived broken. Please send a replacement.",
            "questions": {
                "team": {
                    "type": "choice",
                    "instructions": "Which team should handle this?",
                    "criteria": {
                        "billing": "Charges and refunds",
                        "shipping": "Delivery, damage and replacements",
                        "technical": "Software and service outages",
                    },
                },
            },
        }
    )
    print(response["answers"]["team"])

evaluate returns decisions in answers. generate returns typed scalar and structured fields in result. Neither promises that the selected model will interpret every question correctly. Start with clear instructions and measure your own cases.

Repository samples

Samples exercise this checkout and build its local artifacts. The separate demos repository installs published packages; each Python demo owns its code and data.

PowerShell · repository root 
py samples/build.py native --arch x64
py samples/run.py python --model C:/models/model.gguf
py samples/run.py ts --model C:/models/model.gguf --generate
py samples/run.py csharp --model C:/models/model.gguf --generate
py samples/build.py web
py samples/run.py web

Choose one architecture supported by your build toolchain: x86, x64, or arm64. From inside samples/, use py build.py and py run.py, without repeating the directory.
