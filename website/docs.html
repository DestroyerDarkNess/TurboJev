Quickstart

Run a real decision in five minutes.

The repository samples build a small verified GGUF model once, then reuse the native artifacts from TypeScript, Python, .NET, and Rust.

PrerequisitesPython 3.9+, Rust 1.82+, Node 22+, .NET 8+, CMake, and a native C/C++ toolchain.
PowerShell · repository root
py samples/build.py native --download-model
py samples/run.py ts
py samples/run.py python
py samples/run.py csharp
py samples/run.py rust

For the browser studio, build the independent WASM path:

Browser / WASM
python samples/build.py web
python samples/run.py web
02

Architecture

Portable semantics, replaceable runtimes.

The core receives state and typed questions. An adapter renders the model's real prompt and tokenizer, returns candidate scores, and lets TurboJev validate, normalize, calibrate, and build the response.

statetext · JSON · media
→
typed questionschoice · noul · score
→
TurboJev coreplan · score · respond
→
EvaluationResponsesame shape everywhere

Core owns

  • Schema and candidate validation
  • Execution planning and calibration metadata
  • Typed response construction
  • Order robustness and parity contracts

Adapters own

  • Chat template and tokenizer
  • GGUF, Transformers.js, or custom runtime
  • Media preprocessing and hardware
  • Process, file, and network boundaries

04

Language bindings

Use the idioms of your host.

Each binding owns lifecycle and host ergonomics. The request and response semantics stay the same.

Rs

Rust

Native, strongly typed integration with the crates directly.

crates.io ↗
Cargo.toml + main.rs
[dependencies]
turbojev = "0.28.2"
turbojev-runtime-llamacpp = "0.28.2"

use turbojev::TurboJev;
use turbojev_runtime_llamacpp::{ffi::{FfiLlamaCpp, NativeConfig}, reference_backend, ReferencePromptConfig, ReferencePromptRenderer};

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let runtime = FfiLlamaCpp::open("./model.gguf", NativeConfig::default())?;
    let renderer = ReferencePromptRenderer::new(ReferencePromptConfig::new(
        "my-app-v1", "Choose exactly one allowed code.", "Which team should handle this?"));
    let engine = TurboJev::new(reference_backend(renderer, runtime));
    let answer = engine.classify("My package arrived broken.", ["billing", "shipping", "technical", "other"])?;
    println!("{}", answer.choice);
    Ok(())
}

TS

Node / TypeScript

Worker-backed native calls with typed results and clean async shutdown.

npm ↗
npm install @turbojev/node
decision.ts
import { TurboJev } from "@turbojev/node";

const jev = await TurboJev.load({model: "./model.gguf", nGpuLayers: 0, nThreads: 4});
try {
  const result = await jev.classify("My package arrived broken.", [
    "billing", "shipping", "technical", "other",
  ]);
  console.log(result.choice, result.probabilities);
} finally {
  await jev.close();
}

C

C ABI

Stable UTF-8 JSON ABI for C, Zig, Go, and other FFI hosts.

header ↗
smoke.c
#include "turbojev.h"
#include <stdio.h>

int main(void) {
    tj_engine *engine = NULL;
    if (tj_engine_open_json("{\"model\":\"./model.gguf\"}", &engine) != TJ_OK) return 1;
    char *json = NULL;
    int rc = tj_engine_classify_json(engine, "My package arrived broken.",
        "[\"billing\",\"shipping\",\"technical\",\"other\"]", &json);
    if (rc == TJ_OK) { puts(json); tj_string_free(json); }
    tj_engine_close(engine);
    return rc != TJ_OK;
}

The ABI uses opaque handles, explicit string ownership, and thread-local errors.

05

Multimodal

Media evidence follows the same response contract.

TurboJev does not depend on a particular multimodal checkpoint. An application-selected runtime owns decoding and preprocessing; TurboJev validates the envelope and returns the typed decision.

media evidence
{
  "state": {"contract": "turbojev.media.v1", "modality": "image", "base64": "<encoded bytes>"},
  "questions": {"scene": {"type": "choice", "instructions": "What animal is shown?",
    "criteria": {"cat": "A cat", "dog": "A dog"}}}
}
Included workersSmolVLM2 covers image/video CPU decisions. LFM2.5-Audio covers spoken-intent decisions.
vision sample
python samples/multimodal/setup.py vision
python samples/run.py vision --file photo.jpg --modality image \
  --question "What animal is shown?" --options "A cat" "A dog"
